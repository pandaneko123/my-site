## このブログの仕組み

- **Astro** で静的サイトとして生成
- **Cloudflare Pages** で公開
- 記事は Markdown ファイルを `src/content/blog/` に置くだけ

## Markdown の書き方の例

**太字**、*斜体*、[リンク](https://astro.build/)、`インラインコード` が使えます。

```python
print("Hello, world!")
```

> 引用はこんな感じで表示されます。
